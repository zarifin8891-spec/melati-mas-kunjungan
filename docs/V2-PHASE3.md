# Phase 3 — Weekly social metrics and cohort Dashboard

Added mmr_v2_social with unique Monday/platform rows, nonnegative counters/spend, active admin/marketing RLS and immutable creator metadata. Users may edit with updated_at conflict detection. No hard delete is granted. mmr_v2_social_metrics is a security_invoker view that counts organic leads for the corresponding platform/week. Applied additive migrations: mmr_v2_social_and_cohort_dashboard, mmr_v2_social_row_metrics, mmr_v2_dashboard_all_sales_overdue_scope. Inspect history before applying scripts again.

mmr_v2_dashboard(from,to) is an authenticated, SECURITY INVOKER aggregate RPC. It checks active profiles and returns totals/series without downloading all lead records to the browser. Cohort = lead arrival date within period. Survey = distinct cohort leads with any recorded visit to date. Booking includes currently active Booking/Akad; cancelled bookings do not count. Akad is current derived Akad state. Visit KPI = visit events whose visit date lies in period. These event/cohort scopes are labelled in the UI.

Global overdue KPI and per-sales overdue are across all periods, excluding terminal Akad/Batal. Sales listing includes all lead owners and visit attendants, so an owner with only overdue leads outside the cohort remains visible. Source and sales conversion use lead cohort, while visits by sales use attendant and event date.

Social rows selected by Monday start date, matching workbook. Organic leads require source exactly equal to platform; Iklan Meta and Iklan TikTok are kept separate. Social CPL = weekly-platform spend / matching organic leads; global KPI CPL = selected social spend / all cohort leads. These are different attribution measures and labelled explicitly. Zero denominators return null (display —), not zero acquisition cost. Engagement rate uses total engagement / total reach, not mean weekly rates. Trend shows eight seven-day windows from selected start, as in the template, and may extend beyond selected end; UI says so.

Dashboard V2 is the initial signed-in page. The historical dashboard and legacy visit data remain available. Approved navy #1F4E79 styling and Pie 3D rendering/category colors are retained.
